# Log kinds

Generated by `notchling log kinds --markdown`. Do not edit it by hand: change the registry in `crates/events/src/kinds/` and regenerate it.

A trailing `?` on a field means it is optional, `[]` that it is a list of at most 16. A choice lists its values; an unknown value is read as `other`. No field holds free text.
