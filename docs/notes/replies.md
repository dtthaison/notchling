# Replies

Typing into a session from Chat, the notch or the phone: when a reply waits, how it is typed, pictures, and every way it failed before. The recorded terminal fixtures are in `crates/engine/tests/fixtures/notchling/terminal/`; [recording.md](../recording.md) says how they were made.

Part of the Rust app's notes, moved from `crates/AGENTS.md`; the index is in the root `AGENTS.md`. Keep it true: change the note with the code, and add what bites you under Things that bit before.

- **Couldn't wake.** A finished session that cannot start again (its conversation is open in another terminal or in Claude Desktop) makes `claude attach` print a "Couldn't wake" row instead of a prompt box. `reply/exec.rs::wake_failure` reads it from the screen the look already took, never from a second terminal read, so a wake keeps its number of looks, and checks it before the screen is classified. The row counts only when it is among the last three rows and no prompt rule or `❯` row is below it, so a live session whose scrollback mentions the phrase is not failed, and a stale starting box, a wrapped line or a trailing hint do not hide it. A row that fills the width continues on the next one, and the text after ` — ` is the reason. The try ends as `Failure::Wake(reason)` and the message is tried again on the usual backoff. The Outbox stores the row as `retry`; `Why::Wake` is only on the wire and in the row's shown state, and it stays through the whole wait for the next try (`outbox_postman.rs`, `outbox_rows.rs`). Chat shows "open somewhere else" when the reason names another terminal (`wake_open_elsewhere`) and the reason itself otherwise, with Edit and Remove. An older app reads the row with no `why` and shows it as queued.
