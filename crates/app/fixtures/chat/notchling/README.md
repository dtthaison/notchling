# Chat fixture: Notchling's data folder

The `notchling` folder of the Chat fixture root (`crates/app/fixtures/chat`): where `lanes.json`
would be. This fixture has no lanes, so the folder holds only this note. The layout is the one
every render reads (`NOTCHLING_DATA_ROOT`): `claude` for `~/.claude`, `notchling` for Notchling's
data folder, `codex` for `~/.codex`. Never a `.claude` path.
